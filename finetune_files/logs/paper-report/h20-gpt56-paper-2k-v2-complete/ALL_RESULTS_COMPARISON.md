# 全部实验结果综合对比

本报告汇总论文 FT-Agent、复现主策略、普通 LoRA 与 rsLoRA 的全部 13 个 benchmark、17 个指标，并分别报告 held-out test 和 validation。表中微调结果统一表示为“均值 ± 样本标准差（SD）”；论文列采用论文公开的均值与 SD，其余三列由 3 次独立运行计算。方向归一化差值仅比较均值。

## 对比口径

| 列 | 口径 |
| --- | --- |
| 论文 FT-Agent | 论文主表中 FT-Agent 公开的均值 ± SD |
| 复现主策略 | 本次主复现实验的 3 次均值 ± 样本 SD；允许 validation-only 规则选择 baseline，因此不等同于纯 LoRA |
| 普通 LoRA | 严格配对实验的源 profile，`use_rslora: false`，3 次均值 ± 样本 SD |
| rsLoRA | 与普通 LoRA 除 `use_rslora: true` 外保持一致的配对 profile，3 次均值 ± 样本 SD |
| `Δ方法/参照 ↑` | 方向归一化差值；正数表示“方法”优于“参照”，负数表示更差 |

除 MAE 与 TMS 外，表中指标均以百分数表示。MAE 越低越好，其余指标越高越好；因此 MAE 的方向归一化差值为“参照值 − 方法值”。

## 指标级胜/平/负汇总

胜/平/负按 17 个指标行计数，不对不同量纲的指标直接求平均。

| Split | 复现主策略 vs 论文 | 普通 LoRA vs 论文 | rsLoRA vs 论文 | rsLoRA vs 普通 LoRA |
| --- | ---: | ---: | ---: | ---: |

| Validation | 4 / 0 / 13 | 2 / 0 / 15 | 8 / 0 / 9 | 7 / 1 / 9 |

## 结果摘要

- rsLoRA 相对普通 LoRA 在 held-out test 上为 7 胜、1 平、9 负，没有形成跨任务整体优势。
- rsLoRA 的主要 test 增益出现在 `panorama_noc4pc`、分子理解的 TMS/Acc、分子编辑 Acc 和反应 Acc；主要退化出现在事实核查、数值推理、分子优化与反应 FTS。
- 与论文相比，普通 LoRA 在 held-out test 上仅 2/17 个指标更好，rsLoRA 为 5/17；rsLoRA 缩小了部分任务差距，但不能解释或消除整体复现差距。
